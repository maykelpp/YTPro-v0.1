# YTPro v0.1

Aplicación Android de música con búsqueda, vista previa por streaming y descargas locales. Inspiración visual: YouTube Music y Mornye.

## Componentes
- `app/`: cliente Android nativo.
- `control_api/`: API en Render solo para activación, mantenimiento y control de versiones.

La búsqueda, reproducción y descarga se ejecutarán en el dispositivo. Render no transportará audio ni archivos multimedia.
